Catálogo de diseño para Configuración y tecla de micrófono

Este laboratorio es solo un tablero de decisión: no toca el código de la app. A la izquierda de cada propuesta verás un código (C1…C5 estructuras de Configuración · B/I/G botones, inputs y tarjetas · P pantallas principales · M teclas de micrófono). Cada demo vive dentro de un teléfono simulado y funciona en modo claro y oscuro.

Usá el conmutador de arriba para alternar Auto / Claro / Oscuro y el zoom para comparar cómodamente. Algunos teléfonos traen su propio mini-toggle de tema para probar un único componente aislado.

Cómo elegir: referenciá los códigos en la conversación. Ej.: «usá C1 como estructura, B7 para los segmentados y M4 para el micrófono».

B · Catálogo de controles para Configuración

Referencia visual de los controles pensados para la nueva sección Configuración de VoiceBubble STT. Todas las demos son funcionales: tocá, escribí y cambiá de tema desde el shell para verificar el contraste.

Botones

Siete niveles de énfasis más selección múltiple: de la acción crítica al ajuste silencioso.

Cápsula primaria glass

Vidrio tintado con el accent y brillo interior. Se eleva al pasar el mouse.

B2

Tonal secundaria

B3

Ghost
