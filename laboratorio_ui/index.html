Gestión Rápida de Fragmentos

Animaciones orgánicas con micro-delay háptico al pulsar cada snippet para una apertura suave y elástica de los formularios de edición y confirmación.

Acciones Rápidas del Teclado
✏️ Edición (Azul) 🗑️ Borrado (Rojo)
Modo Editar Snippets (✏️)
Resalta los snippets en azul pulsante. Tocar uno despliega suavemente el formulario con animación elástica.
Modo Eliminar Snippets (🗑️)
Resalta los snippets en rojo pulsante. Tocar uno despliega la barra de confirmación con deslizamiento fluido.
Crear Nuevo Snippet ( ➕ )
Abre directamente el formulario inline en blanco.
Física de Animación Implementada
  • Micro-Delay Táctil (70ms): Al tocar un chip, este se comprime elásticamente (`scale(0.91)`) dando feedback de clic antes de que el formulario emerja.
  • Apertura Elástica (Spring In): El editor emerge con una suave curva cúbica `cubic-bezier(0.16, 1, 0.3, 1)` con un sutil desempañado (`filter: blur(4px) -> 0`).
  • Deslizamiento de Borrado: La barra de confirmación roja se desliza de arriba hacia abajo de forma limpia y precisa.
