Lab Credenciales

Llave en el teclado + sección en Ajustes. La contraseña se escribe una vez y nunca vuelve a mostrarse. La lista muestra el nombre (opcional: nombre + usuario). Un toque pega usuario + contraseña.

Toca la llave → el panel de vidrio tapa el teclado → desliza con el dedo para buscar → Pegar. Arrastra la raya hacia abajo para esconderlo.

Ajustes → Credenciales

Mostrar usuario junto al nombre

Criterios (design.md)

  • Regular por defecto: vidrio negro 45% + blur 24 + borde especular, radio 24 en el sheet.
  • Contraseña jamás visible; sin edición; error → borrar y crear.
  • Sin auth en el teclado: no hay secretos a la vista; el Pegar es la confirmación.
  • Inyección directa usuario → tab → contraseña; nada a portapapeles persistente.
