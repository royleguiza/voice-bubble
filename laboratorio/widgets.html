Widget Notas grande — Dictado que queda

Ocupa toda la fila y altura (4×2 compacto, 4×3 / 5×4 responsive si el usuario estira). App de notas mini: dictás desde el widget, la nota se guarda; tapping en una nota abre edición completa (seguir dictando / escribiendo / pegar).

  • Independiente del historial 20 FIFO. Notas = 50 max, editables, persistentes en almacenamiento interno (SharedPreferences + archivo atómico).
  • Glass Regular grande: blur 24, fill 68% (claro) / 64% (oscuro), borde especular. Tarjetas internas en bgElevated (no glass) — jerarquía design.md §2.
  • Responsive: 4×2 → 3 notas + barra mic; 5×4 → 6–7 notas + search. Grid elástico sin cortes.
  • Targets 44dp, contraste 4.5:1, Reduce Motion = sin wave.

3. FeedbackWidget actualiza RemoteViews: última nota arriba + “Nota guardada”. Sin abrir app.
4. EditarTap nota → PendingIntent con noteId → notes/detail?id=... → editor (texto + dictado continuo + pegar + guardar).

Snippet de layout responsive (Kotlin — conceptual) 
val opts = appWidgetManager.getAppWidgetOptions(id)
val w = opts.getInt(AppWidgetManager.OPTION_APPWIDGET_MIN_WIDTH)
val h = opts.getInt(AppWidgetManager.OPTION_APPWIDGET_MIN_HEIGHT)
val layout = when {
  h < 200 -> R.layout.widget_notes_compact // 4×2
  h < 280 -> R.layout.widget_notes_medium  // 4×3
  else     -> R.layout.widget_notes_large   // 5×4
}
RemoteViews(packageName, layout).also { rv ->
  rv.setTextViewText(R.id.title, "Notas • ${notes.size}/50")
  notes.take(visibleCount).forEachIndexed { i, n ->
    rv.setTextViewText(noteIds[i], n.titulo)
    rv.setOnClickPendingIntent(noteIds[i], pendingFor(noteId=n.id))
  }
  rv.setOnClickPendingIntent(R.id.mic, pendingDictate())
  appWidgetManager.updateAppWidget(id, rv)
}
